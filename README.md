# IT-Industry-Website

A responsive design prototype for a **Real-Time Group Study and Collaboration Platform**.

## Pages

- `index.html` – landing page with hero, features grid, pricing, notifications, and dark mode toggle.
- `session.html` – real-time collaboration session layout with chat, collaborative notes, tasks, and video call panel.
- `profile.html` – user profile, study history, and account settings layout.
- `wireframes.md` – low-fidelity wireframe deliverables.

## Run locally

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
